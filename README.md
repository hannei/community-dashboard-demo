# 社区运营数据看板 Demo

个人数据作品，使用 HTML + ECharts 实现的单文件交互式数据看板，用于展示指标梳理与看板搭建思路。

> **数据声明：页面内所有数据均为模拟的脱敏数据，非真实业务数据。**

## 在线访问

https://hannei.github.io/community-dashboard-demo/

## 三层指标体系（从宏观到微观）
| 层级 | 内容 | 回答的问题 |
|---|---|---|
| 第一层 核心指标 | 8 个指标卡，按流量、浏览深度、互动、内容生产分组 | 社区现在怎么样 |
| 第二层 指标趋势与板块对比 | 6 张趋势图、1 张板块对比图、1 张板块明细表 | 问题出在哪个环节、哪个板块 |
| 第三层 帖子明细 | 按累计浏览量排序的帖子列表 | 具体是哪条内容 |

## 筛选与联动

- **日期区间**：可选择任意起止日期，默认展示最近 20 个完整日
- **板块**：全部板块或单个板块，点击板块对比表的行可切换
- **统计周期**：日 / 自然周 / 自然月

三个筛选器对所有层级联动。核心指标卡同时展示当前周期值和环比。

## 指标口径

| 分组 | 指标 | 口径 |
|---|---|---|
| 流量 | 社区 UV | 统计周期内访问社区板块的去重用户数 |
| 流量 | 平台渗透率 | 社区 UV ÷ 平台 DAU |
| 浏览深度 | 人均浏览页数 | 社区 PV ÷ 社区 UV |
| 浏览深度 | 人均停留时长 | 社区总停留时长 ÷ 社区 UV |
| 互动 | 互动用户数 | 统计周期内产生点赞、评论或分享的去重用户数 |
| 互动 | 互动率 | 互动用户数 ÷ 社区 UV |
| 内容生产 | 发帖用户数 | 统计周期内发布帖子的去重用户数 |
| 内容生产 | 发帖渗透率 | 发帖用户数 ÷ 社区 UV |
| 留存 | 次日留存率 / 7 日留存率 | 周期内新增用户在第 1 天 / 第 7 天回访的比例 |
