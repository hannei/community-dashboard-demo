# 社区运营数据看板 Demo

个人数据作品，使用 HTML + ECharts 实现的单文件交互式数据看板，用于展示指标梳理与看板搭建思路。

> **数据声明：页面内所有数据均为模拟的脱敏数据，非真实业务数据。**

## 在线访问

https://hannei.github.io/community-dashboard-demo/

## 三层指标体系（从宏观到微观）

1. **大盘指标层**：流量规模、用户活跃、内容生产、互动传播四类，含渗透率、互动率等比率指标，排除流量规模波动的影响；
2. **内容板块汇总层**：按板块汇总发帖量、获赞、评论、分享及爆款帖数，用于快速定位异常范围；
3. **帖子明细下钻层**：落到单条帖子，含单帖互动率、传播系数两个衍生指标，用于判断内容质量与扩散能力。

## 交互功能

- 日 / 周 / 月时间维度切换；
- 板块下拉筛选，汇总表与明细表联动过滤，模拟 BI 切片器效果。

## 技术栈

- 原生 HTML / CSS / JavaScript，单文件；
- ECharts 5.4（CDN 引入，需联网加载）。
